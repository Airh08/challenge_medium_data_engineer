## Como use la IA:
Utilice Calude conectado con Deepseeek
* Primero converti el archivo pdf del challenge a un formato de markdown con chatgpt por estas razones:
1. Menor consumo de limites.
2. Mejor razonamiento para los modelos de IA.

* Despues le medi que leyera el archivo y comensara con el punto para generar el script que genera la data simulada, especificando que utilizara python y la libreria de Faker.



utilizare la libreria de faker para simular los datos de un banco y poder utilizar estos datos para los siguientes puntos de la prueba.
